TomoTree package description
============================

TomoTree is a Python library and interactive web application for **image reconstruction
from acoustic tomography of trees**. Sensors (typically 12 or 24) are attached around the
circumference of a tree trunk and short acoustic pulses are sent between every pair of
sensors. The measured travel times — or the derived sound speeds — are then used to
reconstruct a 2D velocity map of the cross-section. Areas with reduced sound speed
indicate internal defects such as rot, cavities, or mechanically weakened wood.

The package provides:

* **Several reconstruction algorithms** — EBSI (Ellipse-Based Spatial Interpolation),
  ERSM (Enhanced Ray Segmentation Method), and SIRT (Simultaneous Iterative
  Reconstruction Technique).
* **Anisotropy correction** — compensates for the well-known effect that radial rays
  travel faster than tangential rays in living wood.
* **Interactive Streamlit web GUI** — load data, tune parameters, and explore results
  without writing any code.
* **Cloud deployment possible** — you can run the web app on a server and access it from any device with a
  web browser.
* **Jupyter friendly API** — you can use the reconstruction algorithms and postprocessing tools in your own
  Python code or Jupyter notebooks.
* **FastAPI REST service** — programmatic access for integration into automated
  pipelines.
* **Rich geometry model** — ``Node``, ``Ray``, ``Segment``, ``Cell``, and ``Grid``
  objects with full cross-references.
* **Postprocessing tools** — binary thresholding, area measurement, wall-thickness
  estimation, moment of inertia, and sound-wood speed calibration.
* **Resistograph integration** — overlay drilling-resistance curves on the tomogram.
* **Export** — tomogram images (configurable DPI), CSV data tables, and statistics.
* **Session save / load** — persist the full application state between browser sessions.
* **Internationalization** — support for multiple languages with easy translation workflow.
* **Extensive documentation** — API reference, user guide, and worked examples.
* **Open source** — MIT license, with code available on GitHub.

.. note::
    The case studies based on TomoTree utilization are described in detail in a forthcoming
    paper (currently submitted for peer review). The full source code is publicly
    available at https://github.com/robert-marik/tomotree.
