Input data units

The TomoTree application internally works exclusively in SI units (metres for distance, seconds for time, m/s for speed). Before any reconstruction is performed, the uploaded data must be converted to these units.

Selecting units in the sidebar

After a dataset directory is selected, an Input data units selector appears in the sidebar. Choose the combination that matches your input files:

Changing the selection clears the cached data and forces a reload, so the new factors are applied immediately.

Custom units

When Custom is selected, two dropdown menus appear:

  • Distance — mm, cm, or m

  • Time — µs, ms, or s

The corresponding SI conversion factors are derived automatically.

Per-dataset override via config.yaml

If a dataset directory contains a config.yaml file with a conversion factors section, those values override the sidebar selection when the option From config.yaml is active. Example:

conversion factors:
  length: 0.01    # centimetres → metres
  time: 1.0e-6    # microseconds → seconds

Any numeric multiplier is accepted. The converted value equals raw_value × factor.

F3D files

Data extracted from binary .f3d files (Picus Sonic Tomograph format) use the same conversion factors as CSV files. The F3D format stores distances in centimetres and travel times in microseconds, so the default cm + µs preset is the correct choice for these files.
